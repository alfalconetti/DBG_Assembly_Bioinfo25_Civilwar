# De Bruijn Graph Assembler & Contig Classifier

This tool implements a genome assembler based on the De Bruijn Graph formalism. It accepts k-mer inputs to construct the graph structure and performs a topology-aware assembly process.

Unlike standard greedy assemblers, this implementation explicitly identifies and handles graph complexities such as sequencing artifacts (tips), allelic variants (bubbles), and isolated components. The assembly engine traces paths through the graph and assigns a specific topological class to each generated contig, providing granular insights into the graph structure directly in the output metadata.
## Key Features

- **Structural Variant Resolution:** Automated handling of *bubbles* (allelic variants/paralogs) and *tips* (sequencing artifacts) during path extension.
- **Advanced Topological Tagging:** Every contig is classified based on its connectivity and shape within the graph (e.g., Linear, Circular, Lariat).
- **Metadata-Rich FASTA Output:** Generates FASTA headers containing median k-mer coverage, length, topological tags and necessary structural information to better understand the origin of the topological complications.




## 📊 Contig Classification Tags

This table maps every possible `tag` generated by the assembly engine, organized by topological family.

## 1. Circular Topologies
*Paths where `start_node == final_node`.*

| Tag | Description | Notes |
| :--- | :--- | :--- |
| `circular_isolated` | Standard circular path. | Found during final catch-all search. |
| `circular_fork_hub_residual` | Circular path from branching nodes. | Extracted during residual hub cleanup when fork_in_hub is true. |
| `circular_with_bubble` | Circular path containing a resolved bubble variant. | Resolved during bubble assembly. Bubble was inside the circular contig. **Should not be possible.** |
| `circular_with_bubble_through_hub` | Circular path with a bubble that crosses a hub. | Resolved during bubble assembly and kept walking through the final bubble node that is an hub. **Should not be possible.** |
| `circular_bubble_resolved_ending` | Circular path ending exactly at bubble convergence. | Resolved during bubble assembly and the final bubble node has no outgoing edges. **Should not be possible.** |
| `circular_through_hub` | A circle that passes through a branching node. | Circular element that has a starting hub and another hub which it passes through. **Should not be possible.** |
| `circular_self_loop_hub` | A direct loop starting and ending at the same hub. | Loop originating and ending in an hub |
| `unknown_circular_like` | Ambiguous circular structure. | Fallback for undefined circular shapes. |

### NOTE
**The only possible circular topologies should be circular_isolated, circular_fork_hub_residual and circular_self_loop_hub**. The other ones are marked mainly due to debug purposes. 
They should not be possible because a circular not-isolated contig must start from hubs used in the assembly process, that are used only when fork_in_hub is false (creating circular_self_loop_hub) or when it is true and are used generating the residuals (creating circular_fork_hub_residual). Both those strategies stop at the first fork found. The other ones are not possible would need fork_in_hub to be True to step walk through a hub, but fork_in_hub True means that all contigs must start from a node with 0 incoming edges, thus making it impossible to be circular.

## 2. Lariat Topologies (Lasso)
*Linear tail leading into a cycle. Detected via `is_lariat()`.*

| Tag | Description | Notes |
| :--- | :--- | :--- |
| `lariat_simple` | Standard lasso structure. | Linear tail + circular head. |
| `lariat_with_bubble` | Lariat containing a resolved bubble. | A bubble is resolved in the assembly in a region of the lariat |
| `lariat_with_bubble_through_hub` | Lariat with bubble crossing an intersection. | The lariat originates resolving a bubble in assembly and also following one of the paths in the bubble final node |
| `lariat_bubble_resolved_ending` | Lariat ending at a bubble convergence node. | The lariat originates resolving a bubble and immediately closes the lasso structure |
| `lariat_through_hub` | Lariat passing through a branching node. | The lariat originates following one of the paths of a hub |
| `lariat_branch_at_hub` | Junction point is a graph hub. | The branching point itself is an hub. It is a specific type of lariat_through_hub |
| `lariat_fork_hub_residual` | Lariat found during hub cleanup. | Lariat originated in the residual procedure when fork_in_hub is True |
| `unknown_lariat_like_from_catch_all` | Lariat found in final search. | Isolated complex structure. |

### NOTE
The only possible structure when fork_in_hub is True are lariat_simple, lariat_with_bubble

## 3. Linear Topologies
*Standard paths with distinct start and end points.*

| Tag | Description | Notes |
| :--- | :--- | :--- |
| `linear_simple` | Standard linear contig. | Clean assembly. |
| `linear_with_tip` | Path ending in a dead-end (tip). | Potential sequencing artifact. |
| `linear_bubble_resolved_ending` | Branch ending at bubble destination. | Potentially resolved allelic variant. A bubble was resolved and the sequence ends in bubble final node |
| `linear_bubble_resolved_extended` | Branch continuing after bubble convergence. | Potentially resolved allelic variant. A bubble was resolved and the sequence continues after the bubble final node |
| `linear_bubble_resolved_extended_through_hub` | Extended bubble branch crossing a hub. | Potentially resolved allelic variant. A bubble was resolved and the sequence continues after the bubble final node which is itself an hub |
| `linear_through_hub` | Path crossing a branching node. | A common beginning, a hub and two different paths |
| `linear_fork_hub_residual` | Linear path from hub cleanup. | Residual linear segment in the residual procedure when fork_in_hub is true. |
| `linear_bubble_branch_bubble_starting` | Linear path corresponding to bubble branch. | Originated when fork_in_hub is False and following a bubble path |
| `unknown_linear_like_from_catch_all` | Linear path from final search. | Isolated linear fragment. |
### NOTE
The only possible structure when fork_in_hub is True are linear_simple, linear_with_tip, linear_bubble_branch_bubble_starting, linear_fork_hub_residual

---

## 4. Dynamic Suffixes (Connectivity)
*Appended to the tags above to describe node-level connectivity.*

* `_bubble_starting`: Contig starts exactly at the **source node** of a resolved bubble.
* `_hub_starting`: Contig starts at a **generic hub** (branching node).
* `_hub_ending`: Contig ends at a **hub** (convergence or new branching).

---
**Note:** Tags like `unknown_...` are fallbacks for structures that do not strictly meet all criteria but exhibit the primary characteristics of that family.
